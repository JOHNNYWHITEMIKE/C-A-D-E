## Technical Architecture

### Frontend Stack
```
React 18.3
├── Vite 7.2 (Build Tool)
├── React Router 7.1 (Navigation)
├── Monaco Editor (Code Editor)
├── Axios (HTTP Client)
└── Custom CSS (Styling)
```

### Backend Stack
```
Python 3.11+
├── FastAPI 0.121 (Web Framework)
├── Uvicorn 0.38 (ASGI Server)
├── Pydantic 2.12 (Validation)
└── Python-dotenv (Config)
```

### DevOps
```
Docker
├── Dockerfile (Backend)
├── Dockerfile (Frontend)
└── docker-compose.yml (Orchestration)
```
